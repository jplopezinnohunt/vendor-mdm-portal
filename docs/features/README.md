## 🔍 Características Principales

### Sistema de Invitaciones

El sistema permite a administradores invitar vendors al portal mediante email con tokens seguros. Incluye diagramas visuales profesionales que muestran el flujo completo del proceso.

👉 Consulta: [Sistema de Invitaciones](./invitations.md)

**Características**:
- Generación de tokens seguros
- Envío automático de emails
- Validación de invitaciones
- Registro de vendors
- Diagramas visuales de flujos y arquitectura
- Integración completa con servicios Azure

### Configuración de Email

Configuración completa para envío de emails tanto en desarrollo como en producción.

👉 Consulta: [Configuración de Email](./email-configuration.md)

**Características**:
- Soporte para SMTP
- Integración con Azure Key Vault
- Templates de email
- Configuración por ambiente
