# 👁️ Ver Diagramas - Guía Rápida

## 🚀 Opción Más Rápida (Sin Instalar Nada)

1. **Abre**: https://mermaid.live/
2. **Abre el archivo**: `docs/features/invitations.md`
3. **Copia el código** de cualquier diagrama (lo que está entre ` ```mermaid ` y ` ``` `)
4. **Pega** en el editor online
5. **¡Listo!** Verás el diagrama renderizado

---

## ✅ En VS Code

1. **Instala extensión**: Busca "Markdown Preview Mermaid Support"
2. **Abre**: `docs/features/invitations.md`
3. **Presiona**: `Cmd+Shift+V` (Mac) o `Ctrl+Shift+V` (Windows)
4. **Verás** todos los diagramas renderizados

---

## 🌐 En GitHub

Simplemente **sube el archivo** a GitHub y los diagramas se renderizan automáticamente cuando veas el archivo en el repositorio.
