# Visual Architecture Documentation Guide

Two approaches for creating professional architecture diagrams:

## 1. AI-Generated Diagrams (GENERATIVE_AI_PROMPTS.md)

Use AI image generators (DALL-E, Midjourney) with pre-crafted "Super Prompts" to generate:
- System architecture diagrams
- Data flow diagrams
- Authentication flow diagrams

**Best for**: Quick, high-quality visuals for presentations

## 2. Manual Diagram Tools (CREATE_PROFESSIONAL_AZURE_DIAGRAMS.md)

Use professional tools with official Azure icons:
- **Draw.io** (Free, recommended)
- **Microsoft Visio** (Professional)
- **Lucidchart** (Cloud)

**Best for**: Editable, maintainable diagrams
