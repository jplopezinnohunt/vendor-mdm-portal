1. [Instalación](./installation.md) - Instala las herramientas necesarias

---

## 🎯 Inicio Rápido

### Requisitos Previos

- **Node.js 18+** y npm
- **.NET 8 SDK**
- Editor de código (VS Code recomendado)
- Cuenta de Azure (para deployment)

### Pasos Iniciales

1. **Clonar el repositorio** (si no lo has hecho)
   ```bash
   git clone <repository-url>
   cd vendor-mdm-portal
   ```

2. **Instalar herramientas necesarias**
   - Ver [Guía de Instalación](./installation.md)

3. **Configurar entorno local**
   - Ver [Desarrollo Local](./local-development.md)

## 🆘 Problemas Comunes

### "dotnet: command not found"
→ Consulta la sección de instalación en [Instalación → .NET SDK](./installation.md#instalación-de-net-8-sdk)

### "Cannot connect to backend"
→ Verifica que el backend esté corriendo. Consulta [Desarrollo Local](./local-development.md#ejecutar-backend)

### Problemas de puertos
→ Revisa la configuración de puertos en [Desarrollo Local](./local-development.md#configuración-de-puertos)
