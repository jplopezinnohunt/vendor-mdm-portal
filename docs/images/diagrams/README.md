Esta carpeta contiene las imágenes renderizadas (PNG/SVG) de los diagramas Mermaid.

## 📋 Diagramas Disponibles

Los diagramas se encuentran en formato Mermaid en:
- `docs/features/invitations.md` - Sistema de Invitaciones

## 🎨 Generar Imágenes

Para generar las imágenes profesionales desde los diagramas Mermaid:

1. **Método rápido**: Consulta [Exportar Diagramas](../EXPORT_DIAGRAMS_AS_IMAGES.md)
2. **Método avanzado**: Consulta [Generar Imágenes](../GENERATE_DIAGRAM_IMAGES.md)

## 📐 Resoluciones Recomendadas

- **Documentación web**: 1920x1080px (PNG o SVG)
- **Presentaciones**: 1920x1080px o 3840x2160px (PNG)
- **Impresión**: 300 DPI mínimo (PNG o PDF)
